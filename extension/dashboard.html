Your Chrome players, controlled here.

  1. Open this extension in the Chrome profile where your games are already signed in. Start each game in its own tab and enable its in-player sound.
  2. Use Add game tabs to select the existing tabs. Add active Chrome tab uses the most recent website tab, including the tab where you clicked Saturday’s toolbar icon.
  3. Choose the viewing monitor and layout, then Arrange games. Existing tabs move into compact Chrome windows. Their pages are not reopened or copied.
  4. Use Make main to enlarge a game, Listen to switch its audio, and Go to game to raise that player and hear it. Changing the main game does not change the selected audio.
  5. Three games give one large game above two smaller players. Four, five, seven, or up to nine games adapt automatically. Choose Equal grid for equally sized windows.
  6. Fullscreen main game shows just the main game across its monitor. Return to multibox restores the whole layout. Filling a monitor with multiple windows uses its available desktop area.
  7. Use End session & restore tabs before reloading, disabling, or restarting Chrome. Tabs return to regular windows, with their original mute settings.

This Chrome version controls real separate windows; they form the multibox on your viewing monitor. The layout overview is a diagram, not a video preview. No video capture, new logins, stream extraction, or cookie copying is used.

Chrome may enforce minimum window sizes. A larger display or fewer games can help if players overlap. Provider page UI remains inside each window; use its theater view if available. Other apps and unselected tabs can still produce sound.

Chrome-wide shortcuts: Alt+Shift+Right cycles audio and Alt+Shift+M mutes selected games. Change them at chrome://extensions/shortcuts.
